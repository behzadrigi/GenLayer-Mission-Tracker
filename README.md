## GenLayer Intelligent Contract Integration

This project now includes a simple GenLayer Intelligent Contract (`GenLayerContract.sol`) to demonstrate integration with the GenLayer ecosystem.

### Features
- Tracks points and missions using Solidity contract.
- Provides functions to add and retrieve points.
- Emits events for mission progress.

### Purpose
By including this contract, the project aligns with GenLayer’s builder requirements and shows how developers can extend the ecosystem with smart contracts and tooling.
